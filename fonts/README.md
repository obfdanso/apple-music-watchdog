# Fonts

Put font files (`.ttf`, `.otf` or `.ttc`) here to use them in the watchdog window without installing them. They show up under **Settings → Appearance → System font**.

This is also how to use **Anthropic Sans** if you have its font files but haven't installed it. It isn't included in this project because it isn't freely licensed.

Font files in this folder are ignored by git, so they won't be committed by accident.
